# Claude Code Videos

Cinematic shorts drawn entirely in code.

- [`liberty/`](liberty/) — **LIBERTY: The American Project**: a 2:15 gold-on-black film about 250 years of the United States, from 1776 into the near future. It has an original electronic score, synthesized in code and locked to the picture on a shared 120 BPM timeline. The picture is drawn with HTML Canvas, rendered headlessly and assembled with FFmpeg. Open `liberty/index.html` to watch it with sound in a browser, or run `node liberty/score.mjs && node liberty/render.mjs` to render the MP4.
