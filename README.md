# Claude Code Videos

Cinematic shorts drawn entirely in code.

- [`liberty/`](liberty/) — **LIBERTY: The American Project**: a 2:15 gold-on-black film about 250 years of the United States, from 1776 into the near future. It is made with HTML Canvas, rendered headlessly and assembled with FFmpeg. Open `liberty/index.html` to watch it in a browser, or run `node liberty/render.mjs` to render the MP4.
- [`american-experiment/`](american-experiment/) — **THE AMERICAN EXPERIMENT**: a 4:56 successor to LIBERTY, framed as the lab log of a 250-year experiment, with an original score synthesized from the same 120 BPM timeline as the picture. In progress: the engine, HUD, full score and the prologue, title and Apollo observations are finished; the other observations run as storyboard slates. See its [README](american-experiment/README.md) and [STORYBOARD](american-experiment/STORYBOARD.md).
