# Claude Code Videos

Cinematic shorts drawn entirely in code.

- [`liberty/`](liberty/) — **LIBERTY: The American Project**: a 2:15 gold-on-black film about 250 years of the United States, from 1776 into the near future. It is made with HTML Canvas, rendered headlessly and assembled with FFmpeg. Open `liberty/index.html` to watch it in a browser, or run `node liberty/render.mjs` to render the MP4.
- [`ode/`](ode/) — **ODE: From the Agora to AI**: a 3:27 film about the story of Western civilization, from the Parthenon to a child asking an AI why the stars shine, ending on "Ode to Joy". It has painted light, a 2.39:1 letterbox, a score written in code and a narrated soundtrack. Open `ode/index.html` to watch it with sound, or run `node ode/render.mjs` to render the MP4.
